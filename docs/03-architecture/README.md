# Architecture & Design

This section covers the underlying design, motivation, and architecture of ZASK (Zero-trust AI-Secured Kernel).

## Documents

- **[Motivation](motivation.md)**: Explains the context of why ZASK exists, the projects it learns from, and the specific gap it aims to fill by integrating semantic AI reasoning into kernel-level enforcement.
- **[Core Features & Capabilities](core-features.md)**: Lists the core design principles and capabilities of ZASK, including kernel-level enforcement, the expressive rule engine, AI resilience patterns, and cloud-native operability.
- **[Architecture](architecture.md)**: Details the multi-tiered enforcement model, component layout, and the flow of events from the eBPF LSM hooks in the kernel up to the AI deliberation engine.
